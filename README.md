
# Single-Phase Four-Level Multilevel Inverter - EEE4022S Research Project

This repository hosts the design and development files for a **Single-Phase Four-Level Nested Neutral Point Clamped (NNPC) Multilevel Inverter**. This inverter project focuses on achieving low Total Harmonic Distortion (THD) and enhanced efficiency for renewable energy applications.

## Key Features
- **Four-Level Output**: Improved waveform quality and lower THD.
- **Control Strategy**: PWM control using the TI C2000 microcontroller.
- **Simulation and PCB Design**: Simulink models and KiCAD PCB layouts for testing and prototyping.
